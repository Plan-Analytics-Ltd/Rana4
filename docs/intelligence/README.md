# Programme intelligence

Backend intelligence services live under `src/services/intelligence/`.

| Subfolder | Responsibility |
|-----------|----------------|
| `benchmark/` | Deliverable and portfolio benchmarking |
| `learning/` | Learning engine, maturity, refresh, lessons learned |
| `prediction/` | Outcome prediction, forecast reliability, expected duration |
| `recommendations/` | Recommendation engine |
| `trust/` | Intelligence trust scoring and explanations |
| `findings/` | Finding generation |
| `drivers/` | Key factor / driver analysis |
| `orchestration/` | Analysis orchestrator and metadata |
| `profiles/` | Deliverable classification and knowledge profiles |
| `shared/` | Types, math, parsing, programme import/export utilities |

Calculations and orchestration behaviour are unchanged — this is organizational structure only.
